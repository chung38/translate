# 移次搞定＋移件翻

正式網址：https://yicipass.com（舊網址 translate-1up.pages.dev 會自動轉過來）

- **移次搞定**：移工宣導文宣、聘僱指南、新聞、法規與實用工具，資料每天自動更新。
- **移件翻**（首頁中間）：上傳 Word、Excel、PowerPoint 或 PDF，譯文直接排進原檔，版面與表格都保留。可翻成繁體中文、泰文、印尼文、越南文、英文。

這個 repo 放網站與翻譯 API，部署在 Cloudflare Pages：推到 `main` 就會自動上線。
文宣、新聞、法規等資料由 [chung38/migrant-poster-hub](https://github.com/chung38/migrant-poster-hub) 的爬蟲每天產生。

各部分放在哪、要改什麼該改哪個檔、金鑰設在哪，請看 **[ARCHITECTURE.md](ARCHITECTURE.md)**。
